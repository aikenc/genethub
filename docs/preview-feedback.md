# 文件预览分享与反馈

预览信息显示项目名、多 Root 的目录名以及拥有文件的机器名和绝对路径。
文件定位仍使用 rootHandle；显示名称不会参与授权。

## 分享

工作台、独立预览页提供分享按钮，可选择 1h、1d、7d。iOS 主屏幕 PWA 的外部打开
操作生成 1h 链接，用户复制到浏览器打开。其他平台外部打开保持当前预览展开；最小化操作
才收起预览。分享访问者可以转发当前链接，沿用原期限。

链接的长期凭据只用于向 Cloud 兑换短期连接凭据，浏览器刷新和重连重新兑换。
Cloud 保存凭据哈希和机器归属，文件内容与反馈保存在拥有文件的 daemon 上。
分享连接只能读取入口和资源清单中的文件，使用文件反馈接口；不能浏览机器、会话、执行命令
或转授权。daemon 每次访问检查期限和撤销状态，传输过程中也继续检查。
旧 daemon 未声明预览权限协议时，Cloud 拒绝兑换预览凭据。

资源清单包含静态引用及拥有者预览中实际加载过的动态资源，最多 512 个文件。
后续才计算出来、尚未加载且未被静态引用的文件不会自动扩大授权；重新体验并生成链接可加入。
隐藏文件、跨 Root 动态资源和清单外文件不开放。

## 反馈

打开预览不会创建反馈。开始批注、保存运行日志或打开反馈窗口时，daemon 创建文件版本绑定
的草稿，并复制源文件作为证据。浏览器仅保存草稿编号，批注和附件由 daemon 持久化。
同一浏览器刷新可以继续草稿；不同分享授权分别拥有草稿。

用户在反馈窗口选择批注、日志和附件，填写说明并提交。提交生成不可变回执，包含反馈编号、
机器、项目、文件版本和证据引用。同一内容重试返回原回执；改变已提交内容需要新建反馈。
用户点击「复制编号和内容」后手动粘贴到会话或传回拥有者。剪贴板不可用时可选中文字复制。
页面返回、BroadcastChannel 和会话输入框不会参与该反馈流程。

拥有者或对应工作区的 Agent 可用公共 CLI 检索提交记录：

```text
genet preview feedback show pf_<编号> --workspace <工作区编号>
```

内容保存在主 Root 的 `.genethub/preview-feedback/drafts/<编号>/`：`draft.json`、
源文件快照、`artifacts/` 和提交后的 `feedback.json`。多 Root 文件的来源另存目录名、相对路径
和原始绝对路径。每项目最多 1000 个草稿、2 GiB 证据；每草稿最多 40 条批注、20 个附件包。
上传复用 Session 的有界分块引擎，预览附件 manifest 使用 `feedbackId` 标识拥有者。
写入采用进程互斥和内核文件锁、私有文件原子替换；JSON 和源文件均视为访问者提供的数据。
