# Workbench 公共设计语言

本约定适用于 GeneHub 工作台、Console 宿主页与公共弹层。用户产物、独立预览文档不继承工作台组件规则。参考 Tencent WeUI 2.6.26 的正文/尾部结构、按压反馈与安全区职责；不加载无消费者的整套 WeUI 控件样式。

## 层次与消费合同

1. `theme.css` 定义语义颜色、`--gh-space-*`、`--gh-type-*`、`--gh-touch-target` 和圆角。新增页面不能覆盖根高度、安全区或通用字号工具类。
2. 公共布局负责可用区域；列表、导航、输入框、对话框消费该区域。页面只组合内容，不计算屏幕高度。
3. 公共交互优先演进已有 ListLayout、FilterBar、EntityIdentity、WorkspaceDetailsDialog、usePageNavigation。不要另建一套弹层或返回栈。

旧页面的 text-xs/text-sm 兼容规则暂保留。新增短标签使用语义字号；迁移消费者后才能删除旧规则。不能用 !important 抵消布局宽度预算。

## 视口与边缘

- html 保留用户 UI 缩放；固定 body 使用动态视口高度除以该缩放，避免按 inset 推断 iOS PWA 高度。无 dvh 支持时回退百分比高度。
- Cloud 与独立 Workbench 均使用 cover viewport 和非透明 PWA 状态栏。旧安装入口可能缓存配置；发布验收必须区分旧入口与重新安装入口。
- 列表底部安全区属于导航；聊天属于输入框的实体背景；独立预览和弹层属于各自容器，嵌入内容不重复消费宿主边缘。
- 键盘只补偿可视视口下沿仍遮住的部分，按 UI zoom 转换；浏览器已经缩小外壳时不再次抬高输入框。pinch zoom 不当成键盘。
- 不使用机型像素补丁、screen.height 布局、负 margin 或仅改背景色遮住空隙。
- `captureLayoutGeometry` 仅导出几何、safe-area、缩放及焦点元素种类，随反馈采集。不读取聊天文本、输入内容或 DOM dump。

## 列表和筛选

- EntityRow 正文 `min-width:0`，尾部操作占真实空间，保持可点击；禁止 absolute bottom 定位操作及手工右 padding 防遮挡。
- 超窄空间允许动作自然换行，不能按“存在任务”固定抬高整行。桌面与触摸都可发现更多操作。
- FilterBar 标签不等分、不换行，筛选区横向滚动，操作区固定。选中项滚入自己的条带，不能滚动整页。
- 状态用同一 attention 投影；任务入口写“查看任务”，不把受阻任务写成绿色“进行中”。
- 触摸目标至少 44×44；图标和文字视觉尺寸独立于目标尺寸。导航短标签使用 navigation 字号，辅助说明使用 label 字号。

## 任务与会话

- 会话 turn 与小队任务独立。小队面板默认一行状态/数量，详细内容进入已有公共对话框，避免头部内嵌第二个长滚动区。
- 展开由用户控制，轮询不抢焦点或自动展开。优先使用关联执行会话标题，无标题用“任务 N”。技术 ID 留给执行记录。
- 原因先给一句摘要，完整原因按需展开。任务等待、执行、停止、受阻、失败分别表达。
- 终止仍直接调用 workflow.cancel；保留提交中、错误和最终结果，不新增 PM LLM 回合。
- 页面切换重置当前会话的面板状态；返回恢复草稿和列表位置。对话框负责焦点归还、Tab 范围和 Escape。

## 验证约定

浏览器专项从真实 Workbench 公共入口检查 320/375/390/430、桌面及特大 UI 尺寸、完整筛选点击、尾部按钮、任务详情与直接取消。截图/几何检查须验证实际边界，不只检查颜色。

Chromium 手机尺寸检查不能声称 iPhone PWA 通过。真实 iPhone 需补充：冷启动、后台恢复、旋转、键盘开关、Safari/独立 PWA、旧/新安装入口，保留同条件几何与截图。任何未覆盖项在交付中明确列出。
