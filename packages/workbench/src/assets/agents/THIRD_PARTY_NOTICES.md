GeneHub is sponsored by or affiliated with the mark owner. Runtime code only
loads the bundled files listed in `sources.json`; custom Agents cannot supply a
remote image URL.

Claude Code is represented by its documented `✱` text glyph. Codex, Gemini and
GitHub Copilot fall back to their names because no suitable current compact
