# Agent asset notices

These marks identify the Agent selected by the user. They do not imply that
GeneHub is sponsored by or affiliated with the mark owner. Runtime code only
loads the bundled files listed in `sources.json`; a script Agent's own icon
arrives as an inline `data:image/` URL from its directory, never a remote URL.

- Cursor assets come from Cursor's official brand package and are used without
  changing their geometry or colours. Refer to the product as “Cursor”.

Codex uses a neutral `C` monogram because no suitable current compact product
mark was identified during the 2026-08-04 review.
