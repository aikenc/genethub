# Agent Chat UX — 五套第一性原理原型

共同前提：输入框是内容容器，不是点击状态。它从一行开始，随内容连续增长，到达可用视口上限后才内部滚动。Agent、模型、权限、思考强度是「下一条消息的运行上下文」，应在输入附近可见，但通过搜索和渐进披露避免挤占写作空间。

## 五个方向

1. **chat-fluid-dock / 流体底座（推荐基线）**
   - 最接近当前产品结构，迁移成本最低。
   - Agent、模型和权限是输入框内的独立入口，不再用一个含义模糊的总入口。
   - 适合直接演进为正式方案。

2. **chat-command-hub / 命令中枢**
   - 面向熟练用户与键盘工作流，强调 `⌘K` 搜索和 `/` 命令。
   - 选择器采用「搜索 + 最近 + 收藏 + 能力标签」，模型数量增长不会增加操作距离。
   - 视觉更像开发工具，信息密度最高。

3. **chat-context-capsules / 上下文胶囊**
   - 将 Agent、模型、权限做成可扫读胶囊，降低“当前到底用什么运行”的不确定感。
   - 圆润、轻量，适合一般用户；焦点态只强化边界，不改变输入框结构。

4. **chat-focus-canvas / 专注画布**
   - 为宽屏和长任务优化，弱化侧栏、扩大对话和输入宽度。
   - 适合多工具结果、长代码和复杂上下文，但移动端自动回落到单列布局。

5. **chat-mobile-deck / 移动优先**
   - Composer 与屏幕底边连接，所有主要触控目标都在拇指区。
   - Agent/模型选择在移动端使用底部 Sheet，兼容安全区；桌面端仍为居中 Dialog。

## 功能覆盖

- 输入：内容自动增高、最大高度后内部滚动、Enter 发送、Shift+Enter 换行、输入法组合态保护。
- 运行：发送、启动/运行态反馈、停止、失败消息保留/回填的设置表达。
- Agent：多 Agent、就绪/能力信息、连接新 Agent、会话锁定语义。
- 模型：关键字搜索、最近、收藏、视觉、长上下文、本地筛选、自动路由。
- 参数：权限/模式、思考强度、记忆会话设置。
- 图片：文件选择、剪贴板粘贴、缩略图、删除、点击大图预览、多图横向滚动。
- 语音：同层级入口、录音波形、实时转写说明、完成后写回可编辑文本。
- 上下文：工作区、Web、MCP 工具、文件提及、Slash 命令。
- 响应式：桌面侧栏、移动单列、底部安全区、移动端底部 Sheet、最小触控尺寸。

原型使用共享的 `chat-shared` 交互底座，保证比较的是信息架构和视觉层级，而不是功能缺失造成的假差异。
