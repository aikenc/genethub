# 内容创作过程接入

## 从工作阶段选择预览形式

目标是让创作者确认“正在做什么、做到哪里、结果是否正确、是否能继续操作”。不要把所有任务都变成一个视频播放器，也不要为了预览已有文件额外引入服务。

| 预览层次 | 典型需求 | 接入方式 | 验收事实 |
|---|---|---|---|
| 阶段产物 | 镜头代理片、合成帧、转台图、材质对照、动画预演、仿真缓存的可视化结果 | 工作区普通文件或静态索引页，使用 HTML Skill | 文件确实生成，标明工程/版本/帧范围/生成时间；不是过期结果 |
| 任务状态 | 渲染/合成/缓存烘焙/导出进度、当前帧、失败原因 | 应用适配器通过登记 HTTP、流式响应或 WS 输出真实状态 | 状态来自实际任务，完成对应存在的产物，失败和取消明确显示 |
| 实时画面 | 视口、实时渲染、引擎运行、数字人实时驱动 | 应用侧采集或原生媒体输出，适配 offer/stop，可信面板播放 | 看见指定工程的持续变化，确认帧率/延迟/音视频及实际媒体路径 |
| 操作回传 | 切镜头、改参数、时间线定位、视口操作、游戏输入 | 按任务接入应用 API/插件或专用输入协议 | 操作确实作用于正确实例，权限与控制者清晰，断线不遗留按键或任务 |

同一流程可以组合多层，例如“合成进度 + 已完成帧缩略图 + 最近代理片”，不一定需要实时串流。大文件采用代理片、缩略图或分段产物；每个由 Asset Preview 打开的文件不超过 64 MiB。工程文件、缓存和模型可作为源数据保留，不能承诺 Preview 原生识别任意专有格式。

## 软件类别与接入示例

以下是工作流设计示例，不是 GeneHub 已内置的软件连接器清单。每次接入都需核对所用软件版本的官方 API、插件、导出和运行方式。

- **影视剪辑、调色和合成**：例如 DaVinci Resolve 等剪辑/调色软件中的时间线代理片，或 Nuke、After Effects 等合成软件输出的指定镜头帧。可先交付带镜头名、版本、时间码/帧范围和色彩说明的阶段文件；需要检查持续渲染时再接入任务状态。不能把浏览器播放结果当成专业色彩监看或音频同步的最终验收。
- **DCC 建模、材质、动画和仿真**：例如 Blender、Maya、Houdini 工程的转台、材质变体、动画预演或仿真迭代。先确认当前对象、相机、帧范围及实际输出；需要视口实时预览时检查应用采集/编码方案。切视角、改参数、时间线拖动分别需要应用控制适配。
- **游戏引擎与实时场景**：例如 UE、Unity 或其他引擎中的场景运行效果。观看与游玩分开验收，确认运行模式和真实实例。UE 的版本、Pixel Streaming 信令及 PIE 限制见[UE 接入](unreal-engine.md)；其他引擎也必须核对自己的接口，不能照搬 UE 配置。
- **数字人**：角色资产、绑定、动画、口型、渲染属于上面的内容制作流程；实时驱动或对话又会连接输入、语音、推理等后端。制作阶段可以只需文件和状态，实时交互再接入[数字人工作流](digital-human.md)，不预设每个数字人都需要 ASR/LLM/TTS。

## 应用适配的责任

1. **确认对象与阶段**：将工程、镜头/场景、版本、帧或时间码、任务 ID 和产物路径用于应用自己的状态展示。当前 GeneHub 服务描述并没有这些创作语义字段，需要适配器提供；不要伪造为 daemon 字段。
2. **连接真实软件**：优先使用该版本支持的脚本/API/插件或可靠的导出结果。窗口捕获若适用，需明确捕获对象、许可和敏感画面边界；当前可信面板没有通用远程桌面采集/输入能力，不能凭空增加浏览器权限来代替源端接入。
3. **明确进程所有权**：runner 只管理自己启动的后端。若适配器连接用户已打开的编辑器，关闭预览应释放连接，不能连带关闭编辑器或丢弃未保存工作。是否退出创作软件是另一项实际操作，不由“停止媒体”暗示授权。
4. **让状态可信**：任务尚未完成、失败或产物仍在写入时明确显示。采用应用确认完成的文件或原子发布方式，标注阶段与新鲜度；已有页面不会因此自动订阅文件变化，实时更新需实现刷新或状态通道。
5. **控制操作范围**：观看不等于授权编辑。参数修改、提交渲染、取消任务和键鼠输入按实际任务约束；断线后清理控制状态，不自动重放写操作。
6. **验证整个过程**：执行一次真实小任务，观察状态变化与产物/画面，尝试失败或取消，再重连。记录未验证的软件/设备/网络，不用示例图案证明专业工具已经接入。

## 服务归属与后台入口

Workspace 组织这次预览，源电脑的 daemon 负责发现与访问本机登记，Session 记录 Agent 启动进程的来源；手机等查看设备是客户端。登记仍按规范化 HTML 入口绑定一次运行，不是永久托管地址。

现有后台进程面板按工作区展示进程树；已登记应用附带服务信息，可筛选“仅服务”、查看可达状态并“打开预览”。支持控制协议的应用还可“停止应用”，请求绑定本次 runId。旧客户端可直接打开登记的入口文件。启动、授权和重连步骤见[启动与分享](getting-started.md)。

关闭预览只释放本次请求与媒体会话。停止应用通过认证协议交给适配器处理；进程树展示不表示可以接管任意外部编辑器。GeneHub 当前没有通用服务启动/重启/日志管理或自动恢复接口，必要的进度、输出和错误由应用提供。交付时保留入口、启动配置及正常停止方式。
