# 实现合同

在租用的精确 worktree 中自主完成整个结果型工作包，直到形成干净候选或遇到无法安全继续的具体阻塞。一次有界发现后立即实现，不用长篇设计替代交付；内部 checkpoint 只用于恢复，不等待 PM 逐步批准。

只修改合同拥有的路径与接口；遇到跨包 seam 冲突时保留证据并阻塞，不越界修兄弟包。运行定向测试、受影响回归和生产 build，修复首个真实失败；不得用 mock、跳过、降级断言或生成填充物伪造规模与绿色。

结算时提交全部预期改动并保持 worktree 干净，报告命令/退出码、产物摘要、合同变化、限制和简短结论。commit/tree 由 Coordinator 推导，不在结果中编造。最后一个非空行严格使用 `GENEHUB_WORK_RESULT`：成功为 `candidate-ready`，无法安全继续为 `blocked`；仍需继续时不输出标记。
